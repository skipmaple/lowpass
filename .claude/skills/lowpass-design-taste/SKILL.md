# lowpass 设计口味

## 一句话

lowpass 长得像一张**每天要读的纸报**：暖黑墨、带纹理的浅纸、1px 墨线、反白块、一点鼠尾草绿；四种字体各管一个角色；页面上只有数据，没有装饰性文字。参考站 niccolomiranda.com 提供的是**材料与装置**，不是尺度与自我表达（见 `reference/site-survey.md`）。

## 何时用

- 画任何新页面或组件之前；改现有页面之前；评审别人（或自己）的稿子时。
- 不用于：技术选型、后端逻辑、PRD 范围决定（那是产品负责人的事）。

## 先复用，再创造

所有值先从 `reference/lowpass-tokens.md` 取：颜色 6 个令牌，字号 8 档，线宽 2 档，字体 4 个角色。需要新值时，先问"能不能用已有的表达"，答案几乎总是能。

## 四个字体角色（每个字符只属于一个）

| 看到的内容 | 用 | 不用 |
|---|---|---|
| 任何中文，包括夹着数字的短语（9月7日、第 36 周）、来源名后的中文词 | 霞鹜文楷 Screen | Newsreader、Noto Serif SC、等宽 |
| 源站给的英文：标题、简介、摘要、仓库名、来源名（Hacker News、GitHub Trending） | Newsreader | Bodoni、等宽 |
| 纯数字与记号：分数、评论数、时间、star、序号、发布时间、页码 | Maple Mono NL | 文楷、Newsreader |
| 报头 LOWPASS、LP 邮戳 | Bodoni Moda 900，40px 以上 | 任何其他位置、任何更小字号 |

元数据行只放数字与记号（▲ 312 · 评论图标 145 · 5h）；中文单位不进元数据；元数据里的日期写成数字（09-07 06:12）。按钮、期头、标题里的日期是中文短语（9月7日），整体用文楷。

## 颜色只有一种用法

墨在纸上。鼠尾草绿只出现在三处：今日新增徽章（前三名）、推荐理由左侧 2px 竖线、插图里的太阳与星。**新页面不给绿色新角色**：搜索命中、选中态、链接、提示一律用墨（加粗、下划线、反白）表达。没有第二个彩色，没有渐变，没有阴影，没有圆角。

只有一个阴影例外，已经定过：**整张纸落在深色底上的那层投影**（`tokens.css` 的 `.paper { box-shadow: 0 30px 80px … }`）。它不是装饰，是「一张纸放在桌上」这个比喻本身——纸与底之间没有它就分不开。纸面**里**的任何元素都不许有阴影。

## 结构装置（从参考站取来的可复用手法）

- 80px 墨色报头黑带；56px 文楷日期做每页的"期头"。报头右端的 **32px 头像圆圈**是唯一一个圆形（`Masthead.tsx` 的 `borderRadius: '50%'`）：头像位就是圆的，方框读起来像按钮。这不是"圆角"的口子，别拿它去给别的元素开圆角。
- 分区靠 1px 墨线与 2px 墨线，不靠卡片。
- 切换靠横向并排索引条：当前项反白成墨块，其余描边，来源名 32px；不做下拉、不做侧栏 facet、不做竖排书脊（试过，产品负责人认为交互反直觉）。
- 强调靠反白块：标签（22px 高墨底纸字）、行内强调词、按钮。
- 列表单栏、十条一致：不放大第一条，不分两栏，不三栏并列；层级靠导航装置与字体。
- 图标与插图：墨线木刻感，45° 排线做阴影，装 1px 框或直接做 40px 小图标；不用 emoji，不用彩色插画。
- 状态：一句事实 + 一个时间（今日抓取失败，已通知管理员 / 上次成功 9月7日 06:11）；空态按 PRD 6.3 只有"一句原因 + 一个动作"。
- 手机：24px 边距，条目上下各 24px，长名字允许折行，宁可页长不挤。

## 文案

读者页面上出现的每一行文字都对应一条数据字段或 PRD 附录 B 里的既定文案。不写口号、导语、图注、栏目说明、安抚句、统计装饰（"共 30 条 · 3 个来源"被删过）。PRD 明确要求的计数（如搜索结果数）除外。

## 交付前自检（每项都要能指出证据）

1. 页面上每个汉字都是文楷，每个数字都是 Maple，每个英文内容都是 Newsreader，Bodoni 只在报头。
2. 绿色只在三个既定位置；没有新颜色。
3. 字号全部落在 12/13/15/20/22/26/32/40/56。
4. 没有圆角、阴影、卡片底色、第二栏并列列表、放大的头条——两个已定的例外除外：整张纸落在深色底上的投影、报头 32px 头像圆圈。
5. 每行文字都能指出它对应的数据字段或 PRD 文案。
6. 状态与空态只有事实、时间、一个动作。
7. 新装置能在 `reference/site-survey.md` 的 14 种手法里找到出处，或说明为什么必须新造。

## 常见偏差（基线测试里真实出现过）

| 偏差 | 改法 |
|---|---|
| 中文摘要或译文排进 Newsreader | 中文一律文楷，混排用 `mixed()` 那套按字符段切分 |
| 来源名 "Hacker News" 排进等宽 | 来源名是拉丁内容，用 Newsreader；等宽只给数字与记号 |
| 用绿色做搜索命中或选中 | 用墨：加粗或 1px 下划线；绿色不扩展角色 |
| 自加"共 N 条 · 0.24 秒"之类统计装饰 | 删掉，除非 PRD 6.2 写了要显示 |
| 空态写安抚或建议句 | 一句原因 + 一个动作，不多 |
| 参考站的 500px 巨字、感叹号文案、肖像 | 不取；只取材料与装置 |
