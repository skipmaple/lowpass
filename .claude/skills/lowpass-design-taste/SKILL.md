# lowpass 设计口味

## 一句话

lowpass 长得像一张**每天要读的纸报**：暖黑墨、带纹理的浅纸、1px 墨线、反白块、一点鼠尾草绿；四种字体各管一个角色；页面上只有数据，没有装饰性文字。参考站 niccolomiranda.com 提供的是**材料与装置**，不是尺度与自我表达（见 `reference/site-survey.md`）。

## 现行阅读界面规则（2026-10-28）

用户要求「有新意和秩序」的阅读界面，并明确保留纸质主色调。本节覆盖下文相冲突的历史版式。暖纸 `#E8E3DA`、纸纹、墨色 `#1D1D1B`、次墨 `#55504B` 与四种字体角色保持。

- 日刊、周刊、搜索和收藏均围绕连续阅读列组织。日刊与周刊的阅读列左边界对齐期头版心，保留舒适行长；标题、译文、摘要与理由先完整呈现，关联操作随后，收藏不悬在远处空白。
- 日刊顶部不再摆三块来源面板或重复顺序编号。来源目录默认收起，原生链接按需展开；栏首以紧凑来源名和 1px 小面积强调色细线衔接正文，不另造巨型标题区或右侧装饰。
- 周刊优先突出每期独特主题，来源、期号和原文入口作为次要上下文。板块目录默认收起，展开是轻量文字链接。归档中主题与来源有明确主次。
- 周刊长正文在屏幕上使用桌面 18px、手机 16px，保持 1.8 倍行距与现有阅读列；打印仍沿用原字号。
- 收藏只显示无框图标，保持 ARIA 名称、状态与 44px 触控目标；取消后的事实及恢复动作可见。日刊时间使用 12px 次墨文字、没有时钟图标，写明提交／发布／收录语义，不与阅读内容争层级。
- 日刊跨来源标题与正文保持同一稳定纸面，停滚即停、上滑回退；减少动态效果直接显示终态。保留深链、历史恢复、焦点、完整内容和不可变数据边界。

## 何时用

- 画任何新页面或组件之前；改现有页面之前；评审别人（或自己）的稿子时。
- 不用于：技术选型、后端逻辑、PRD 范围决定（那是产品负责人的事）。

## 先复用，再创造

所有值先从 `reference/lowpass-tokens.md` 取：颜色 6 个令牌，字号 9 档，线宽 2 档，字体 4 个角色。需要新值时，先问"能不能用已有的表达"，答案几乎总是能。

既有宽屏例外（PR #33，2026-09-17 已合并）：1920px 以上保留 1440px 内容宽度与 920px 阅读列，期头日期 64px、摘要/译文/理由与页面上下文 16px。其他字号仍走基础九档；本轮不扩展该例外。

## 四个字体角色（每个字符只属于一个）

| 看到的内容 | 用 | 不用 |
|---|---|---|
| 任何中文，包括夹着数字的短语（9月7日、第 36 周）、来源名后的中文词 | 霞鹜文楷 Screen | Newsreader、Noto Serif SC、等宽 |
| 源站给的英文：标题、简介、摘要、仓库名、来源名（Hacker News、GitHub Trending） | Newsreader | Bodoni、等宽 |
| 纯数字与记号：分数、评论数、时间、star、今日新增、序号、发布时间、页码；元数据行里源站给的拉丁短名（语言名、作者名） | Maple Mono NL | 文楷、Newsreader |
| 报头 LOWPASS、LP 邮戳 | Bodoni Moda 900，桌面 40px、手机 26px | 任何其他位置、其他字号 |

元数据行只放数字、记号、线性图标，以及源站给的拉丁短名（GitHub 语言名、RSS 作者名），都用 Maple；不用 `▲` / `★` 字符，也不用圆点分隔（产品负责人决定，见 `docs/design/notes/2026-09-17-metadata-icons.md`；图标尺寸与间距见 `reference/lowpass-tokens.md`）；中文单位不进元数据；元数据里的日期写成数字（09-07 06:12）。按钮、期头、标题里的日期是中文短语（9月7日），整体用文楷。

## 颜色只有一种用法

墨在纸上。鼠尾草绿只出现在三处：今日新增徽章（前三名）、推荐理由左侧 2px 竖线、插图里的太阳与星。**新页面不给绿色新角色**：搜索命中、选中态、链接、提示一律用墨（加粗、下划线、反白）表达。没有第二个彩色，没有渐变，没有阴影，没有圆角。

2026-09-17 第二轮评审修订：暖纸色覆盖整个窗口，不再使用深色外框和整纸投影。纸面与阅读宽度分离；短页纸面至少充满视口，正文仍限制行长。

## 结构装置（从参考站取来的可复用手法）

- 80px 墨色报头黑带；56px 文楷日期做每页的"期头"。报头右端的 **32px 头像圆圈**是唯一一个圆形（`Masthead.tsx` 的 `borderRadius: '50%'`）：头像位就是圆的，方框读起来像按钮。这不是"圆角"的口子，别拿它去给别的元素开圆角。
- 分区靠 1px 墨线与 2px 墨线，不靠卡片。
- 日刊连续阅读（2026-10-21，D35）：全部来源按配置顺序装在同一篇正文里；顶部横向并排索引条改为原生页内目录，描边、不设选中块，来源名桌面 26px、平板 20px、手机 13px。每栏用现有小图标、来源名（桌面 26px、手机 22px）与一条 1px 墨线衔接，不加大编号、页签、排线、吸顶装置或播放按钮。
- 强调靠反白块：标签（22px 高墨底纸字）、行内强调词、按钮。
- 列表单栏、十条一致：不放大第一条，不分两栏，不三栏并列；层级靠导航装置与字体。
- 兴趣标签紧跟标题最后一个词（所有宽度同一条规则，2026-10-14 产品负责人选定）；放不下就整个换到下一行行首，不靠右悬挂。书签在行末自己的一列。
- 图标与插图：墨线木刻感，45° 排线做阴影，装 1px 框或直接作小图标（尺寸见 `reference/lowpass-tokens.md`）；不用 emoji，不用彩色插画。
- 状态：一句事实 + 一个时间（本期抓取失败，已通知管理员 / 上次成功 9月7日 06:11）；说「本期」不说「今日」，往期页面上也是这几句。空态按 PRD 6.3 只有"一句原因 + 一个动作"。
- 手机：24px 边距，条目上下各 24px。标题和已存摘要完整展示；压缩刊头空白、目录默认收起，不牺牲正文行距。兴趣标签紧随标题。

## 动效

动效表达材料，不表达自己。只有三个动作：墨走（反白块与墨线移动）、翻页（换一期）、盖章（确认）。不弹跳、不发光、不做装饰性视差、不接管滚动、不循环。日刊有一个明确例外：来源交接由滚动进度控制（D35）；停滚即停，上滑原路回退，同一位置对应同一画面，不自动补完；其他正文不随滚动入场。系统「减少动态效果」开启时，所有状态瞬间切换，开场与日出直接显示终态。

- 令牌（值在 `app/frontend/styles/motion.css`）：`--dur-1` 120ms（颜色、下划线、图标填充、菜单展开）；`--dur-2` 240ms（墨块平移、盖章、按钮漫墨、弹层、列表换入）；`--dur-3` 360ms（翻页、开场）；`--ease-out` cubic-bezier(0.2, 0.7, 0.2, 1)（出现、停稳）；`--ease-move` cubic-bezier(0.65, 0, 0.35, 1)（从 A 到 B）。更长的一次性插图动画（登录页日出）用这几档相加，不另起数值。
- 只动 transform、opacity、clip-path、stroke-dashoffset 与颜色类属性；不动布局；不引入动画库。
- 时刻（PRD D34）：日刊跨来源（下一栏外层栏首从视口高度 95% 移到 65% 时，进度从 0 到 1，空间曲线使起止平顺；标题、现有细线与完整正文作为同一纸面接入（6vh，48–64px），内部间距固定，首条进入主要阅读区域前恢复普通滚动；正文维持实墨，不分段追色，不增加标题后留白；上一栏保持正常位置，没有固定时长、时间补间或惯性追赶；首次定位、刷新与阅读恢复采用当前位置的进度；短栏与异常事实静态完整呈现，避免裁掉内容或焦点）；翻页（前一期 / 后一期与 ← / →：新页固定最终坐标、只淡入，旧页沿原方向退出 24px 并淡出，360ms；其余整页跳转只淡入淡出，240ms；旧日期保留尺寸在新期头位置交替；首次可信输入同步收尾，继续原生默认动作。2026-10-24 批准的本地候选，验收边界见 `docs/design/notes/2026-10-24-m2-native-input.md`）；盖章（收藏）；墨线（悬停：链接下划线加深，描边按钮墨从底部漫满；可选中的控件悬停只加下划线，反白专指选中）；开场（每个标签页会话首次整页加载，≤ 600ms）；日出（登录页，约 1 秒，一次）；弹层（菜单、对话框、提示条、目录项淡入）。新动效先问「它是这三个动作之一吗」，不是就不加。

## 文案

读者页面上出现的每一行文字都对应一条数据字段或 PRD 附录 B 里的既定文案。不写口号、导语、图注、栏目说明、安抚句、统计装饰（"共 30 条 · 3 个来源"被删过）。PRD 明确要求的计数（如搜索结果数）除外。

## 交付前自检（每项都要能指出证据）

1. 页面上每个汉字都是文楷，每个数字都是 Maple，每个英文内容都是 Newsreader（元数据行里的拉丁短名除外，走 Maple），Bodoni 只在报头 LOWPASS 与页脚 LP 邮戳。
2. 绿色只在三个既定位置；没有新颜色。
3. 字号落在 12/13/15/20/22/26/32/40/56；1920px 以上仅上述既有宽屏角色可用 16/64。
4. 没有圆角、阴影、卡片底色、第二栏并列列表、放大的头条——唯一的圆形例外是报头 32px 头像圆圈（触控区 44px）。
5. 每行文字都能指出它对应的数据字段或 PRD 文案。
6. 状态与空态只有事实、时间、一个动作。
7. 新装置能在 `reference/site-survey.md` 的 14 种手法里找到出处，或说明为什么必须新造。
8. 时间动画只用两种缓动、三档时长（或它们相加）；D35 直接跟随滚动位置，无时间补间。只动变换与墨色等既定属性；减少动态效果时全部关闭。

## 常见偏差（基线测试里真实出现过）

| 偏差 | 改法 |
|---|---|
| 中文摘要或译文排进 Newsreader | 中文一律文楷，混排按字符段切分（实现用 `app/frontend/lib/typeset.tsx` 的 `Mixed`；画布的 `mixed()` 落后于定稿，别照抄） |
| 来源名 "Hacker News" 排进等宽 | 来源名是拉丁内容，用 Newsreader；等宽只给数字、记号与元数据行里的拉丁短名（语言名、作者名） |
| 用绿色做搜索命中或选中 | 用墨：命中词 2px 墨色下划线（PRD D22）；选中态用加粗、下划线或反白；绿色不扩展角色 |
| 自加"共 N 条 · 0.24 秒"之类统计装饰 | 删掉，除非 PRD 6.2 写了要显示 |
| 空态写安抚或建议句 | 一句原因 + 一个动作，不多 |
| 参考站的 500px 巨字、感叹号文案、肖像 | 不取；只取材料与装置 |
| 给新控件加弹跳、回弹缩放或随滚动触发的入场 | 只用墨走、翻页、盖章三个动作；入场只在开场、弹层与已确认的日刊来源交界（D35），来源交接只跟随当前位置，不自动播放 |
