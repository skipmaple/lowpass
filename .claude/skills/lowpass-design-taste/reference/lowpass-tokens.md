## 已用的装置

- 80px 墨色报头黑带：LOWPASS 纸色 Bodoni + 文楷导航 + 搜索/头像图标。
- 期头：56px 文楷日期，右侧叠放 13px 等宽发布时间与 20px 星期；右端前一期/归档/后一期 40px 描边按钮（手机 44px 方形图标按钮）。
- 来源切换：三条横向并排索引条，当前项反白成墨色块，其余 1px 描边；44px 墨线小图标 + 来源名 Newsreader 600 32px（按样例站显示字体的尺度放大）；手机版三格横排、图标在上名字在下。竖排书脊方案被否（交互反直觉），不要再提。
- 条目：序号（等宽灰字）、标题（细下划线，悬停变实）、说明、元数据、兴趣标签（墨色反白小块，22px 高，纸色文字）、推荐理由（左 2px 鼠尾草绿竖线，文楷 15/1.7）。桌面标签在右列，手机标签与序号组成眉行。
- 状态：期头旁 1px 描边小标签（时钟图标 + 延迟生成于 07:05）；失败来源在索引条名下一行小字，内容区留日出小图 + 一句事实 + 上次成功时间。
- 页脚：LP 邮戳、明早 06:00 · 下一期、最新周刊链接、前后期按钮。
- 插图：墨线木刻感、45° 排线做阴影，装在 1px 框里或直接作图标；四幅原创（低通日出、讨论气泡、分支与星、焊接）。

## 产品负责人的口味（多次确认）

- 少即是多：每源前 10；读者页上不出现任何非数据文字（口号、导语、图注、条数统计、栏目说明都被删过）。
- 有重心：不要三栏并列、不要两栏列表；层级靠导航装置与字体，不靠放大某一条。
- 有温度但不土：拒绝冷灰的斯堪的纳维亚风、拒绝赭石/珊瑚的暖色、拒绝双色 riso；接受纸报材料感 + 手写感文楷 + 一点鼠尾草绿。
- 呼吸感：手机 24px 边距，条目上下各留 24px；宁可页面长，不挤。
- 画布只放产品界面；审核、样张、对照放进 docs/design/notes。
