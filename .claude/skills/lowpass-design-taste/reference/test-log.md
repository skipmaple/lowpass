# skill 测试记录

写法遵循 superpowers:writing-skills：先让代理在没有 skill 的情况下做一件真实设计任务，记录偏差，再针对偏差写规则，再带 skill 复测。

## 任务

"为 lowpass 写搜索结果页设计规范：配色、字体、结构、结果行、筛选、空态、一件刻意不做的事，附一行结果的 HTML 草稿。"（子代理，可读仓库，不可提问。）

## 基线（无 skill，2026-09-09）

代理读了 pages_front3.py 与 notes，令牌大体正确，但出现四类偏差：

1. 中文摘要排进 Newsreader（字体角色错）。
2. 来源名 "Hacker News" 排进 Maple Mono（等宽只该给数字与记号）。
3. 给鼠尾草绿新角色：搜索命中词加 2px 绿色下划线（绿色只有三个既定位置）。
4. 自行添加统计装饰："128 条结果 · 0.24 秒"，以及空态里的建议句"试试更短的关键词"。

做对的：单栏、1px 线、反白标签、分段描边筛选而非侧栏、复用日出插图做空态、不做圆角与卡片。

## 结论

skill 正文因此以"角色表 + 颜色单一用法 + 自检清单 + 常见偏差表"为主，用正向配方而不是禁令堆叠；重点堵字体角色、绿色角色、装饰文案三处。

## 复测（带 skill，同一任务，2026-09-09）
