# Reader features

The primary surface is the development web UI at `http://127.0.0.1:3000`. Launch and doctor are in `../SKILL.md`. Each file below is one `scripts/drive` argument.

- [Login](login.md) — development reader sign-in
- [Daily issue](daily.md) — latest daily issue at `/`
- [Search](search.md) — query, empty result, `search_logs` row
- [Favorites](favorites.md) — the reader's collection
- [Weekly](weekly.md) — latest weekly, or the year archive
