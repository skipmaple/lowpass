# A/B/C 按钮与导航状态验收

2026-11-06。检查对象为 `http://127.0.0.1:3000` 的真实 Rails / Inertia 前端，不是 HTML 预览。A 层叠清晨、B 双声部、C 展开阅读的字体、版式与组件语言保留。

## 已修正

| 问题 | 修正位置与结果 |
| --- | --- |
| 禁用的文字操作与分段选项仍出现悬停强调 | `themes-controls.css`、`motion.css`：排除 disabled / aria-disabled / busy，等待态使用 wait 光标，禁用态不再响应悬停 |
| 主导航顶部、后台横向导航的焦点框被裁切；A 深色导航焦点不清楚 | `themes-controls.css`、`themes-admin-workspace.css`：焦点框内缩，后台框颜色跟随当前可读前景；桌面未选中的主导航补足悬停反馈 |
| 图标硬编码全局墨色，深色搜索按钮的图标不清楚，也不跟随控件状态 | `Icon.tsx`：默认继承 currentColor，保留明确传入的语义色 |
| A 后台有色页头的等待按钮文字与边框对比不足 | `themes-controls.css`：等待按钮使用所在区域的前景与边框令牌 |
| 收藏搜索、缺期补生成、兴趣设置的等待语义与标签宽度不一致 | `Favorites/Index.tsx`、`Daily/Show.tsx`、`InterestAreaRow.tsx`：aria-busy、PendingLabel 与禁用状态一致；兴趣删除确认使用危险操作角色 |

翻期导航在默认、悬停、焦点与禁用状态下保持透明背景。没有重做三套刊头、来源导航或阅读骨架。

## 浏览器检查范围

Chrome，桌面 1440 × 900 与手机响应式视口 390 × 900；手机启用触摸模拟。页头额外检查 320 宽度。不是实体手机验收。

- 前台 54 个页面组合：日刊、周刊、日刊归档、周刊归档、收藏、搜索、账户设置、登录、404 × 三主题 × 两种宽度。156 组可见控件记录默认 / 悬停 / 键盘焦点，存在禁用态时也检查禁用态。
- 后台 42 个页面组合：信息源、新建、编辑、抓取记录、刊物管理、设置、用户 × 三主题 × 两种宽度；153 组状态记录。无横向溢出或页面脚本异常。
- 导航 6 组、240 条状态记录：菜单互斥、Escape 返回触发器、方向键 / Home / End、Tab 退出、外部点击或触摸关闭、主题单选键盘进入、移动后台导航末项可达。
- 等待状态 6 组：收藏搜索、兴趣保存、删除确认；按钮宽度稳定，图标跟随文字，aria-busy 与 disabled 一致。所有检查失败列表为空。
- 页头与 403 补验 9 组：1440 / 390 / 320 × 三主题，主导航焦点不裁切，后台页头等待文字与图标一致。

等待态通过浏览器拦截并暂挂请求，截图后中止，不向服务端提交后台修改或触发抓取 / 模型任务。403 使用浏览器初始化时替换 Inertia 页面标识的 UI fixture，渲染真实 Forbidden 组件；这不是权限验证。权限回归由系统测试覆盖。

`/admin/jobs` 是 Mission Control 独立引擎，不使用 A/B/C 样式；本轮检查其导航入口，没有重做第三方面板。
