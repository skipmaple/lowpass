## 远端 Linux 补充修正

首轮远端运行暴露 `0177.0.0.1` 的 libc 解析差异：macOS 与 Linux 可能把同一地址按十进制或八进制解释。开发显式 DoH 路径现在先严格验证 IPv4 规范表示，拒绝前导零、整数、十六进制及尾点写法，再由 Surfguard 校验公网地址。IPv6 继续原有校验；不发额外 DNS，也不放宽私网拦截。

新增拒绝断言在 macOS 先失败、修正后通过；定向 HTTP 测试 36 项／136 断言、完整 Rails 1176 项／8689 断言通过，两文件 RuboCop 与独立安全复核通过。最终 GitHub CI 以 PR 当前提交的检查为准。

### 搜索焦点测试的激活前提

本地完整并行运行复现两个搜索焦点断言失败。现场诊断确认：`document.activeElement` 已是可见搜索框，但 `document.hasFocus()` 为 `false`，因此 `:focus` 无匹配；页面不是打印模式，也没有隐藏或失去输入框。为该测试类显式模拟激活的浏览器文档，结束后恢复。没有手工聚焦输入框，也没有删除或放宽自动聚焦、Tab、清除与强制颜色的原有断言；每次加载还会检查文档确实激活。

原失败种子 `1571` 复验：250 个系统测试、18055 次断言，0 失败／错误／跳过；独立代码复核无 P1/P2。
