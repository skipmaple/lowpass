# 条目元数据图标统一

2026-09-17，按产品负责人要求，日刊元数据统一使用项目的 Lucide 图形数据与 Morphicons 渲染。此决定替代早期设计稿中 `▲` / `★` 字符及圆点分隔的示例。

- 得分用向上箭头，评论用对话框，发布时间用时钟，GitHub Star 用线性星形。统一 14px 图框、1.75 描边，继承次墨色；数字继续使用 13px Maple Mono NL。
- 图标与数字间距 6px，组间距 16px。每组不拆行，窄屏可在组间换行。今日新增徽章保留既定鼠尾草绿。
- 评论链接悬停或键盘聚焦时，由单气泡变为双气泡；焦点仍在链接上时，鼠标离开不会撤掉变形。图标固定尺寸，数字不随动画移动。
- 评论外链保留新标签页与安全属性，补齐可读名称和焦点框；按产品反馈去掉评论数下划线，用图标变形、墨色加深和焦点框反馈交互。手机点击范围至少 44×44px；得分和时间只表示信息。
- 320px 实机视口审核发现原报头横向溢出，故仅在宽度不超过 360px 时收紧报头内边距及间距，保留品牌字号、账户按钮大小与正文 24px 纸边。

浏览器检查覆盖 320px / 390px 手机视口、键盘焦点、HN 三组元数据与 GitHub 星标；独立审核提出的 44px 触控问题已修正。
