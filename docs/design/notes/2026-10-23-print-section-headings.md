# 周刊打印板块标题与首条保持同页

当前 A4 打印样本（2026-W42，34 条、33 幅真实配图）有六处板块标题留在前页，首条从下一页开始。日刊来源标题已有 `break-after: avoid`；周刊的 `.weekly-section-head` 遗漏该规则，计算值为 `auto`，紧接的文章则是 `break-inside: avoid`。

仅在既有 print 媒体中给周刊板块标题加 `break-after: avoid`。不把整个长板块设为不可分页，不改屏幕样式、字体、内容或图片。

## 失败与单变量验证

- 基线：真实应用本地 Chrome 155，A4，应用原有页边距；六个孤标题出现在 6→7、10→11、15→16、22→23、25→26、27→28 页。
- 同页断言只读取 PDF 派生的标题与首条页码，基线实际退出 1。
- 只注入上述一条规则后，七个板块标题均与首条同页，断言退出 0；同一提取与分类算法保留。
- 34 条文字、标题 URL 与域名完整；33 幅嵌入图的解码字节和尺寸逐项 SHA 一致。页数从 30 增至 31，无文字和图片均为空的页面。第 6 页只有一整幅既有配图，不能将“没有可提取文字”误报为空白页。

## 边界

超过单页可用高度的周刊文章仍允许自然分页，正文与图片全部保留。本修正不靠裁内容实现绝对不跨页，也不改写既有产品契约。
