# 字体声明的累计体积预算

PR #103 后，原始获奖品质基线 `aee2d5f` 的累计 CSS gzip 增量为 6185B，超过 D4 的 4096B；首屏 273.50KiB 合格不能覆盖这个差距。

正文文楷有 97 个字体分片。其字符范围写成许多独立区间，区间中有字体包未支持的汉字。生成脚本现在仅桥接 U+3400–9FFF 内、相邻两段之间的单一码位洞，且该点不能出现在任一原始声明范围或任一分片的 cmap 中。这样将两段合成一段，不改变任何已有字的有效范围、字形、声明顺序或字体文件。界面字体失败时的 vendor 回退也保留；曾考虑排除界面已覆盖码位的方案因会削弱回退而撤回。

桥接的 1324 个码位本来就没有文楷字形，仍由系统字体回退。它们可能额外触发一个不含对应字形的分片请求；没有扩大实际字形支持，也不声称所有输入请求数都减少。范围仅限汉字区，不触及组合符、格式控制符或段落分隔符。

报头文本由既有 `text-transform: uppercase` 显示为 LOWPASS，邮戳为 LP。Bodoni 子集只留实际使用的大写字母与空格，移除未使用的小写；所用字形、度量和版权信息保留。日期内联字体和其他应用字库不变。`script/subset_fonts` 同时生成正文声明，`--check` 校验其是否过期。

新增 `script/frontend_delta_size`，本地和远端 CI 都检查全部页面 JS/CSS 的累计增量。原始构建的 37 项 JS/CSS 原字节、路径及 SHA256 冻结在 `vendor/frontend-budget/aee2d5f.json.gz`，脚本固定包指纹并逐项校验；数据只被解压、校验和压缩，不执行。该包逐字节来自原基线构建及其已验证清单。Zlib 1.2.12 的历史总数是 JS 173833B / CSS 45550B；其他平台由同一个运行时分别压缩原始字节与当前产物，比较增量，不将旧压缩库的绝对数字套到新库，不加容差、不换基线。当前 manifest 的全部条目均计入，包括异步和后台资源，排除未引用的本地旧指纹缓存；缺少当前资源时失败。

验收分别检查字符范围、真实字体选择、字形度量、字体迟到的日周刊回归、页面前后渲染、完整 CI 和上线后的生产。有限布局样本不推导整体 CLS 或普遍加载速度；手机按用户要求跳过，Windows 未提供。
