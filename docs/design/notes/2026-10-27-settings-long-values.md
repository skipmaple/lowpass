# 设置页长地址完整换行

生产 Chrome 的 375px 后台设置页被一条备份存储地址撑到 539px。32 字符主机前缀与存储域名组成连续长词；`.kv-value` 中的文字没有可用断点，手机的一列网格随最小内容宽度扩张，481–768px 的两列布局则出现文字越过值列边界。

在既有 `.kv-value` 上增加 `overflow-wrap: anywhere`，允许放不下的长值换行。保留完整原文、四字体角色、字号、纸边、线条与操作目标；不截断、不隐藏溢出，不改数据或后台操作。

回归使用虚构的长存储地址，在 320、375、390、481、600、768、1024、1440、1920、2560px 检查实际页面宽度、完整文本和每个文字行矩形。旧版真实失败为 320px 页面宽 539px；修复后十宽均无越界，相关四个系统测试通过。文字矩形断言同时防止用裁切掩盖问题。

真实 Chrome 的生产数据临时预览也覆盖十宽，全部保留文字且无横向越界；预览仅限专用标签页，不能当成部署后验收。完整本地 CI 通过，独立代码审查无发现；生产发布及验收另记交付回执。

八项复核：本次修正改善排版与响应式；留白、层级、色彩和原创装置沿用现行纸报设计；动效与微交互规则未改。这只证明该缺陷的修正，整站八项无差距的目标仍待全部要求闭合。

发布门禁补充：首次远端扫描使用更新的漏洞库，检出部署依赖 `net-ssh 7.3.3` 的七条公告。本地同步漏洞库后也能复现失败。按现有依赖约束只更新该包到 7.3.8 及其校验和，新增的 logger 依赖已在锁文件中；没有修改忽略列表。更新后的扫描通过，最终完整 CI 与部署结果另记回执。[上游安全公告](https://github.com/net-ssh/net-ssh/security/advisories/GHSA-qpg5-fx6p-8cq3)。
