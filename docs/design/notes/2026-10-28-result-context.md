# 搜索与收藏：所在期只出现一次

## 现场与处理

生产搜索 `/search?q=Rust` 的每条日刊日期、周刊周次与板块在标题前和底部各出现一次。用户新增的 UI 约定要求避免不必要的次级标签和说明。R-4.6、R-10.6 要求这些事实及链接存在，没有要求重复位置。

所在期统一放在原有底部链接中；标题前保留刊物、来源，以及与所在期不同的发布时间。保留完整链接名称、搜索返回位置与焦点、原文、新标签页行为及收藏操作。没有改动发布内容、快照或查询。

375px 复核另发现：周刊长链接把书签挤到单独一行。普通操作行现在让所在期链接平衡换行，短中文词不拆字，原文与 44px 书签保留空间。收藏取消后的状态和恢复按钮仍可另行排列，避免挤压内容。

## 八项重看

参照沿用[上一轮的作品与证据](2026-10-28-result-reading-measure.md)：Seasoned、The Trace、The Content Architecture。本轮重看 Seasoned 实站；Webby 官方获奖页与 FWA 官方 RSS 可读取，Awwwards 入口仍超时，不将其作为新核实的获奖记录。

| 项目 | 本轮结果 |
| --- | --- |
| 排版 | 标题前去掉重复周期，字体与 780/920px 阅读列保持一致；所在期按词平衡换行。 |
| 留白 | 普通周刊操作行不再因书签单独换行增加一整行空白。状态变化时允许必要空间。 |
| 层次 | 刊物与来源负责辨识，标题和译文负责阅读，底部负责返回与收藏；同一期只说明一次。 |
| 色彩 | 继续用纸、墨和次墨区分层级，未新增颜色或降低对比。 |
| 动效 | 收藏盖章及取消退墨保留，新增布局没有动画；本轮静态对照不代替整体动效验收。 |
| 微交互 | 返回期、外链、收藏三个动作的原顺序与 44px 目标保留；检查取消、恢复及焦点。 |
| 响应式 | 实际本地页面检查 320/375/1270px，长词与 1920px 阅读列沿用完整浏览器回归。真实手机按用户要求跳过，Windows 环境不可用。 |
| 原创性 | 强化纸报阅读单元自身的层级，未照搬参考站的书脊、配色或动效；这一改动不足以证明全站八项已无差距。 |
