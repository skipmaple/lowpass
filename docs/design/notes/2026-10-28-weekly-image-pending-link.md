# 慢图状态中的原图入口

图片没有天然尺寸且懒加载尚未开始时，图片框宽度暂为 0；原图入口此前按框的右边缘定位，320 像素页面中入口左侧为 -20px，越过屏幕边缘。现在入口最左不超过图片框左边；图片宽至少 44px 时仍与图片右边对齐。此改动不影响原图尺寸、比例或请求。

自动化浏览器在 320、375、1440 宽度复现未加载状态并检查链接位于正文内；也检查图片加载成功后的对齐、44px 操作区域、图文顺序和横向溢出。已有多图、焦点测试继续覆盖。实际手机按要求跳过，真实 Windows 未验收。

本轮按八项检查：排版与留白保留已定正文节奏；视觉层次让原图入口始终留在阅读列内；色彩沿用纸墨令牌；动效未变；微交互保留原生链接与触控尺寸；响应式检查了上述模拟宽度；原创性仍延续技术纸报，并未由局部修复证明总体品质。参考作品的桌面首屏观察记录在任务目录 `weekly-reference-20261028/award-comparison.md`；三个参考作品的动效和完整阅读流程尚未逐项实测，不能据此认为八项已达到获奖标准。
