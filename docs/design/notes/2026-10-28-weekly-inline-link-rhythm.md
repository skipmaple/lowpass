# 正文链接与阅读行距

第 415 期《3D 版〈看不见的城市〉》中的正文链接在桌面把单行由约 28px 撑到 44px，导致同段中不同文字行疏密不一致。对照 [The Trace 的实际正文](https://www.thetrace.org/2026/10/gun-violence-redlining-jacksonville-fl/)，它的句内链接沿用正文行距与下划线；Lowpass 使用自己的纸墨风格及混排字体，不照搬其页面。

本次限定于周刊句内引用链接：有精细指针且可悬停、没有粗指针的屏幕设备使用原生行内链接，行高与正文一致，长链接允许换行；有粗指针或输入能力未知的设备保持 44px 高度。混合设备通过后置粗指针规则保留较大目标，但未用真实混合设备验收。其他按钮和链接不变；焦点、链接文字、地址与新标签行为不变。

这是一项实现取舍：设计令牌此前对所有操作目标要求至少 44px，本次仅对纯精细指针设备上的句内链接作例外；触屏目标仍维持 PRD 6.3 的 44px 要求。鼠标用户可点击的面积会缩小。W3C [WCAG 2.2 目标尺寸说明](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum)对段落内链接允许例外，这不代表它对所有使用者都同样容易点击。

曾验证以负外边距保留 44px 链接高度并压回正文行距；相邻段落的链接热区重叠 5px，会造成操作歧义，因此撤回该方案。模拟触屏在 320–1440px 的八个宽度检查目标高度与文本、括号、键盘焦点；桌面模式检查正文行高与长链接换行。未在真实手机或 Windows 测试。

## 八项对照

1. 排版：桌面句内链接与正文统一行距；手机保留较大的触控行，仍未消除其疏密差异。
2. 留白：桌面多链接段的行间不再被单个链接撑大；段落间距不变。
3. 视觉层次：下划线仍标示引用，正文与链接在同一阅读基线。
4. 色彩：保持纸色、墨色和原有下划线颜色。
5. 动效：沿用原有悬停反馈；未新增运动。
6. 微交互：触屏保留 44px；桌面目标变小，键盘顺序和可见焦点保留。未证明所有输入方式均无障碍。
7. 响应式：模拟宽度和长链接已检查；真实手机、Windows、混合触屏设备未验收。
8. 原创性：保留 Lowpass 的纸报语言；此局部修复不能证明整站已有获奖作品的辨识度。
