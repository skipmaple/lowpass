# 周刊引用的展示依据

阮一峰周刊的普通 Markdown 引用此前会在正文直接显示 `>`。新抓取的周刊在原文逐行清洗后与完整正文一致时记录引用段落范围；存在代码、嵌套引用、内容不一致或位置冲突时保留原有展示。记录中的正文依然包含原有标记。

第 415 期只对两篇经过严格匹配的条目提供展示索引：“3D 版《看不见的城市》”的范围为 `[3,6)`、`[13,20)`；“Deno 项目结束了”为 `[6,11)`。对照依据为周刊仓库提交 `a17ecb0043d312f4b2acc5c56e60d513f6fce40c` 中 `docs/issue-415.md`（SHA-256 `4caaa49730caf7b0467e48ddb0be4680134a97043d00a59aac1e00e68adc3218`）。该提交晚于本期发布；匹配证明的是这份固定版本与已保存条目的标题、链接、分组、完整清洗正文和图片序列一致，不证明它就是发布时使用的提交。

展示索引还校验刊期、来源、条目身份、排序和正文及图片序列的摘要；任何不符均回退。索引只添加到响应副本，不改刊期、条目、收藏或图片位置。正文重新分段时，不再使用旧正文上的引用或强调位置。
