# 周刊正文中的参考链接

清洗后的周刊正文只保存纯文字，源文中的多个参考地址以前会消失。新抓取的阮一峰周刊在完整清洗结果与正文逐字一致时，额外记录普通链接所在段落、Unicode 字符范围和 HTTP(S) 地址；不改正文或摘要。包含代码、嵌套标记、异常地址、截断内容或无法完整验证的情况不记录。地址不会自动访问；链接采用原生新标签页、可见下划线和键盘焦点，屏幕阅读名称带附近文字以区分同名链接。

第 415 期以固定源文件 `docs/issue-415.md`（仓库提交 `a17ecb0043d312f4b2acc5c56e60d513f6fce40c`，文件 SHA-256 `4caaa49730caf7b0467e48ddb0be4680134a97043d00a59aac1e00e68adc3218`）对照已发布条目的身份、标题、链接、板块、完整正文及配图序列。两篇完全匹配的文章分别恢复 5 个和 2 个正文链接。该版本晚于刊期发布，只证明与当前已存内容一致，不证明发布时原文版本。独立展示索引不写回刊期、条目、收藏或图片位置；正文分段被重建、身份或内容不匹配时回退。

后续重新核对固定原文与只读条目快照：另有 25 条严格匹配，增加 28 个引用，含封面出处、作品、投稿与言论出处；第 6 条与固定版本不匹配，继续保留原样。合计 27 条、35 个引用；匹配规则与上述相同，任何已有 `reference_links` 字段均优先保留。

本次增补在本地对封面、作品、言论和失配条目实测 320、375、1440px；为避免测试访问外网，配图请求被阻止，预览用于检查文字、链接与横向溢出，不代表图片完整加载的实景。原文测试样本只规范行尾空白，核对清单仅含排序、匹配结果和身份指纹，不包含生产数据库记录。独立复核逐个核对了引用文字、字符范围和目标，发现第 6 条 URL 失配，已排除。

窄屏短链接与相邻中文括号、闭合标点一起换行；触屏链接高度不小于 44 像素，纯鼠标的句内链接保持正常行高，见 `2026-10-28-weekly-inline-link-rhythm.md`。系统测试覆盖 320、375、390、481、600、768、1024、1440 像素的正文与链接顺序、横向溢出、触控高度、键盘焦点和展示副本不改记录。真实手机按用户要求跳过；没有 Windows 环境。

## 本轮八项复核

- 排版：恢复链接下划线和括号组合，源文顺序与字句保持；实文 375px 与桌面预览已检查。
- 留白：链接的触控高度可能增加该行行高；已检查密集链接段，但并非所有长度或所有语言的穷尽验收。
- 层次：正文、引用和链接可区分；正文中的链接以墨线表达，不新增按钮卡片。
- 色彩：使用既有墨色及下划线令牌，不引入新色。
- 动效：链接沿用原有悬停下划线，不引入新运动。
- 微交互：原生键盘焦点、新标签页提示、重复名称的上下文与触控高度均有检查。
- 响应式：八个目标宽度在桌面浏览器模拟；真实手机与 Windows 未验收。
- 原创性：保留 Lowpass 的纸面与字体角色；仅属于局部修复，不能证明整体已达到获奖水准。
