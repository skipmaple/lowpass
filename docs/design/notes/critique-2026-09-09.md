# 设计评审：lowpass 日刊页（纸报版，每源前 10）· 2026-09-09

审查对象：画布第一页 Main（含产品负责人在画布上删除的三处文案：报头下标语、数据带斜体导语、插图图注）。视角：高级 PM 与高级 UI 设计师。

## 总体印象

第一眼看到的是 LOWPASS 报头，不是内容。报头黑块、数据带、索引条合计约 700px，正文从第二屏才开始。作为每天早上要打开的工具，这是海报而不是版面。风格已经对了，问题在配比与克制。

## 可用性

| 发现 | 严重度 | 建议 |
|---|---|---|
| 首屏无内容：前约 700px 全是报头、统计与索引 | 严重 | 报头缩成一行式（72 到 96px）；期头日期与发布信息同一行；删除数据带与索引条；内容在 250px 内出现 |
| 缺少状态设计：某源失败、无新内容、空刊、延迟生成在版面上无表现，而 PRD 明确要求 | 严重 | 为栏设计"今日抓取失败"占位：保留栏头，正文一段说明与重试入口；期头加状态标 |
| 没有手机版：三栏在 390 宽不可用 | 严重 | 分段切换或纵向堆叠；报头缩到 56 到 64px |
| 日期出现三次：报耳、数据带、前后期按钮 | 中 | 只留期头一处大日期；报耳改为导航与发布时间 |
| 数据带里的"抓取用时""昨日全部成功"是运维数据 | 中 | 移到后台；读者页只留"06:12 发布 · 30 条" |
| 索引条与栏头重复计数，"本期三栏"是填充词 | 中 | 删除索引条；前后期、归档并入报耳右侧 |
| 链接没有可见的可点性，只有悬停下划线 | 中 | 标题加 1px 30% 墨色下划线或行尾箭头；整行可点 |
| 栏尾外链措辞不一致：完整榜单 / 全部 | 轻 | 统一 |
| 头像入口没有"设置"的线索 | 轻 | 点头像出菜单，在稿上注明 |

## 视觉层级

- 第一眼是 LOWPASS，应当是今天的日期和三栏标题。
- 阅读流是报头、数据带、索引条、栏头插图、栏名、列表。插图横在栏名之上，打断了栏名到内容的直接关系；三张并排像三张贴纸，抢戏。
- 强调错位：Hackaday 栏灰色摘要文字量大，视觉分量重于第一位的 Hacker News；Bodoni 序号 20px 与 17px 标题抢注意；GitHub 栏十个绿徽章排成一列，是全页唯一彩色，过跳。
- 建议：插图缩为 40 到 48px 放在栏名左侧作图标，或只保留在空态；序号改 Maple Mono 13px 灰色；徽章只给前三名上色，其余文本。

## 一致性

| 元素 | 问题 | 建议 |
|---|---|---|
| 字体 | 一页七个家族：Bodoni Moda、Newsreader、Oswald、Noto Serif SC、Noto Sans SC、文楷、Maple Mono | 收敛为四个：Bodoni（报头）、Newsreader（正文，中文回退 Noto Serif SC）、文楷（期头）、Maple（元数据与小标）；去掉 Oswald |
| 元数据 | Maple Mono 里的"评论"回退成 Noto Sans，粗细字宽都不一致 | 元数据只用数字与符号，或中文部分改用正文字体 |
| 大写 | text-transform 作用在中文字符串上 | 只对拉丁字段设置 |
| 线 | 索引条 2px、行分隔 1px 35%、页脚 2px，三种权重 | 两档：结构线 1px 实色，行分隔 1px 35% |
| 栏尾 | 完整榜单 / 全部 | 统一 |

## 可访问性

- 对比：次级墨色 6.2:1，徽章 7.6:1，报头纸色字 13:1，均达标。
- 字号：栏目小标 11 到 14px 大写偏小；最小 12px，尽量 13px。
- 点击目标：前后期按钮高 34px，低于移动端 44px；桌面 40，移动 44。
- 语义：栏名已用 h2；列表序号是装饰 span，实现时用有序列表。
- 暗底：纸外 #1D1D1B 与纸的强对比在大屏夜间有眩光风险；降到 #2A2825，或随系统主题。

## 做得对的

- 报纸隐喻与"期"的心智一致；纸感、墨线、Bodoni 报头配 Newsreader 正文有格调。
- 三栏按来源的数据形态各排各的：纯列表、带简介、带摘要。
- 每源前 10 的密度合适；插图原创且风格统一。

## 优先级修订清单

1. 首屏重构：一行式报头，期头日期与发布信息同行，右侧前后期与归档；删数据带与索引条。内容起点上移约 450px。
2. 状态与手机：失败、无新内容、延迟状态；390 宽版本。
3. 减噪：插图缩为栏名旁小图标或只留空态；徽章只给前三名；序号降级；字体收敛到四个。
4. 可点性与一致性：标题下划线或行尾箭头；栏尾措辞统一；线权重两档；元数据不混排。
5. 细节：报耳日期删除；最小字号 12；按钮高 40。

产品负责人在画布上删掉标语、导语与图注，读作一条规则：读者页面上不放任何非数据的文案。后续所有页面照此执行。
