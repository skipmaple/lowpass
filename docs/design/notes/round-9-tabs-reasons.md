# 第九轮 · 单栏、tab 切换、每条带推荐理由（2026-09-09）

产品负责人意见：首条不放大，与其余九条一致；不分两栏，改一栏；加有设计感的 tab 快速切换订阅；新增需求：参照 daily-digest skill，每条都带推荐理由。

## 结构

- 报头 80px 黑带，日期行与前后期、归档不变。
- 来源切换：三条并排的纸报式索引条，各带 40px 小图标、Bodoni 来源名与一行说明（等宽数字加衬线中文）。当前来源反白成墨色块，与报头黑带呼应；其余描边。一次只显示一个来源，页面高度从 2600px 回到 1900px 以内。
- 条目：单栏十条格式一致。序号（等宽灰字）、标题（20px，细下划线）、说明（GitHub 简介或 Hackaday 摘要）、元数据、右侧兴趣标签（描边小签）、推荐理由（15px，左侧 2px 鼠尾草绿竖线）。绿徽章仍只给 GitHub 前三名的今日新增。
- 状态：失败或无新内容的来源直接写在索引条说明里，内容区只留失败说明与上次成功时间；期头延迟标签不变。
- 手机：三条索引条等宽 44px 高，兴趣标签并入元数据行。

## 推荐理由的产品定义

写进 PRD v0.3.3 的 D16 与 5.9：每条 20 到 60 字中文，必须点名兴趣画像里的一个领域，相关度低时直说；生成与发布解耦，失败不阻塞发布；兴趣画像全局一份，管理员在后台维护；模型服务由产品负责人选（ADR T8 待定）。样稿里的理由与标签是按初始兴趣画像写的示例。
