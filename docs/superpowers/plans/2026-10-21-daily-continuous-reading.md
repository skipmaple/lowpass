# 日刊连续阅读与来源过渡实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 日刊的全部来源按既定顺序连续呈现，自然滚动进入下一来源时播放已确认的短过渡。

**Architecture:** 来源目录由原生 hash 导航建立历史，Inertia 的 popstate 同步当前 URL 与加密状态，所有来源正文持续挂载。被动 scroll / resize 监听在 RAF 内读取不受位移影响的栏首位置，将视口高度 95% 到 65% 的区间经起止平顺的空间曲线映射到 CSS 进度变量；useLayoutEffect 在首次绘制前同步当前位置。标题、细线与完整正文在内部 sheet 中等量接入（6vh，48–64px），标题与首条间距固定，进入主要阅读区前落定；短栏与异常状态静态完整呈现。无时间动画、循环 RAF 或惯性追赶。旧来源与条目深链、历史位置和完整正文打印保留。

**Tech Stack:** Rails 8、Inertia React、TypeScript、原生 scroll / requestAnimationFrame、CSS animations、Vitest、Rails system tests。

**Spec:** 用户在本次对话中确认的连续阅读与动效原型；`docs/superpowers/specs/2026-09-08-mvp-prd.md` 6.2、D34；`.claude/skills/lowpass-design-taste/SKILL.md`。

## Global Constraints

- 颜色、字体、字号继续使用现有令牌；正文单栏，每源条数与后台配置不变。
- 不增加大编号、页签、排线、吸顶导航或播放按钮。
- 只动 transform、opacity 与墨线；正在阅读的上一来源保持稳定。
- 减少动态效果、打印与动效不可用时，全部内容始终可读。
- 不改变发布数据、鉴权、审计、收藏接口与源抓取行为。
- 首屏资源不超过 300 KB；完整验证遵守 `config/ci.rb`。

## Review Focus

- 某来源抓取失败或没有条目：事实句保留，后续来源仍可继续阅读。
- 搜索与收藏的条目 hash、旧 `?source=` 深链：定位正确，hash 优先。
- 来源目录跳转、离开页面再后退：正文完整，阅读位置不会被初始化重置。
- 浏览器首次载入、恢复滚动位置、减少动态效果：不把已在视口中的正文重新隐藏或动画化。
- 打印与首屏开场：不重复渲染来源，不与跨来源动效叠加或遗留透明文字。
