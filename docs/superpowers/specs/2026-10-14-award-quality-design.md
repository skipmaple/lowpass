### 4.4 动效系统（新增一节，写进设计 skill）

**原则**

动效表达材料，不表达自己。只有三个动作：墨走（反白块和墨线移动）、翻页（换一期）、盖章（确认）。不弹跳、不发光、不视差、不随滚动播放、不接管滚动、不循环。系统开了「减少动态效果」时，所有状态瞬间切换，开场和日出直接显示最终画面。

**令牌**

| 令牌 | 值 | 用于 |
|---|---|---|
| `--dur-1` | 120ms | 颜色、下划线、图标填充、菜单展开 |
| `--dur-2` | 240ms | 墨块平移、盖章、按钮漫墨、弹层、列表换入 |
| `--dur-3` | 360ms | 翻页、开场 |
| `--ease-out` | `cubic-bezier(0.2, 0.7, 0.2, 1)` | 出现、停稳 |
| `--ease-move` | `cubic-bezier(0.65, 0, 0.35, 1)` | 从 A 到 B 的移动（取自参考站的位移曲线） |

只动 transform、opacity、clip-path、stroke-dashoffset 和颜色类属性；不动布局；不引入动画库。

**时刻**

| 编号 | 名称 | 行为 | 验收 |
|---|---|---|---|
| M1 | 墨块平移 | 切来源时，墨块从原来源滑到新来源（`--dur-2`、`--ease-move`），墨块经过的地方文字即时反白。实现：叠一份 `aria-hidden` 的反白副本，用 clip-path 裁到当前项，切换时过渡 clip-path；像素级对齐，索引条换行时同样成立。新来源的列表淡入并上移 6px（`--dur-2`） | 逐帧检查：墨块里的字始终是纸色，块外是墨色，不错位；读屏与 Tab 顺序不变 |
| M2 | 翻页 | 点「前一期」「后一期」：报头不动，正文像翻页。「前一期」新页从左边进、旧页向右出；「后一期」相反。位移 24px 加淡入淡出（`--dur-3`、`--ease-move`），期头大字日期在原位交替。其余整页跳转（换了页面或路径的 Inertia GET 访问：报头导航、从归档进某一期、从搜索结果进所在期）只做正文淡入淡出（`--dur-2`）。保留状态的访问、局部刷新、轮询、表单提交都不做，所以切来源、筛选不受影响。用浏览器原生的 View Transitions（Inertia 已支持），不支持的浏览器直接切换 | 录屏；Inertia 的滚动恢复、换页后焦点移到 h1、后退与前进都不受影响 |
| M3 | 盖章 | 收藏：墨从书签底部涨满（clip-path，`--dur-2`），按钮轻轻一压（0.92 → 1，`--ease-out`）。取消：墨退下，不压。失败回滚走同样的退墨 | 两态仍靠形状区分；录屏 |
| M4 | 墨线 | 标题等链接的下划线由 30% 墨加深到实墨（`--dur-1`）。描边按钮（前一期、归档、阅读最新日刊等 `.ctrl`）悬停时墨从底部漫满、字转纸色（`--dur-2`）；实现是两端同色的背景尺寸动画，看到的是实墨块，不是渐变。索引条和分段控件这类「可选中」的控件，反白只表示已选中，所以未选中项悬停时只给名字加 1px 下划线，不反白 | 每类控件都有悬停态；不可点的 `.ctrl-off` 没有 |
| M5 | 开场 | 每个标签页会话的第一次整页加载时依次出现：期头大字自下而上露出并上移 8px（`--dur-3`）；期头 2px 底线从左向右画出（延迟 60ms）；索引条或搜索框淡入（延迟 120ms）；列表最后淡入（延迟 180ms）。总长 ≤ 600ms。Inertia 内部跳转、后退缓存恢复、减少动态效果时都不播 | CLS 仍为 0；本地 LCP 比改动前增加 ≤ 250ms；同一会话里刷新不重播 |
| M6 | 日出 | 登录页：太阳从地平线下升起（裁在地平线以上），光芒依次画出，水纹从左向右画出，约 1.2 秒，只播一次。文字和按钮立即可用，不等动画 | 录屏；减少动态效果时直接显示最终画面 |
| M7 | 弹层 | 头像菜单向下展开（`--dur-1`）；确认对话框遮罩淡入、纸卡上移 8px 落定（`--dur-2`）；提示条从上方滑入（`--dur-2`）；周刊「板块目录」展开时高度过渡（`--dur-2`） | 录屏；焦点管理不变 |
| M8 | 键盘翻页 | 日刊、周刊详情页：焦点不在输入框、索引条、菜单、对话框里，且没按修饰键时，← / → 等同于「前一期」「后一期」，带 M2 的翻页。页面上不加任何说明文字；链接带 `aria-keyshortcuts` | 系统测试：← 到前一期，→ 到后一期；最新一期按 → 没有反应；在输入框里按 ← 不翻页 |

### 4.5 插图

沿用现有四幅原创的木刻语言：墨线、45° 排线、可以装进 1px 框。新增两幅：

- **翻开的书**：阮一峰周刊的来源图形，进 `SourceMark` 体系（支持反白时把挖空处填成墨），用在周刊来源横带上。顺带还掉 `Illustration.tsx` 里「Task 18 做周刊页时再给它一幅自己的」那笔旧账。
- **缺页**：一张对折的报纸，正中被裁掉一块矩形，缺口里是排线阴影。用在 404 与 403。

## 7. 自查流程与检查清单

**每一轮**：实现 → 截图矩阵 → 量指标 → 按清单逐条打勾 → 按标尺自评打分 → 列出没过的项 → 修 → 下一轮。每轮的评分表和证据写进 `docs/design/notes/2026-10-14-quality-rounds.md`。

**截图矩阵**（页面 × 宽度）

- 页面：最新日刊（三个来源各一张）；日刊空刊与抓取失败两种状态（用样本数据造）；周刊详情；日刊归档；周刊归档；搜索（未搜索、有结果、无结果）；收藏（有、空）；账户信息；登录；404；403；后台的信息源页与设置页（只查和读者页共用的装置）。
- 宽度：320、375、390、481、600、768、1024、1440、1920、2560。

**检查清单**（每条都要有证据）

1. 设计 skill 原有的 7 条自检照旧全过：字体角色、绿色只在三处、九档字号、无圆角无阴影、每行文字有出处、状态只有事实和动作、装置有出处。
2. 矩阵里没有横向溢出、重叠或孤悬的元素；线宽只有 1px、2px 两档。
3. Q1–Q5、T1–T6、C1–C4、E1–E2、D1–D3 逐条验收通过。
4. M1–M8 逐条录屏或逐帧检查；动效进行中照样能点、能滚；减少动态效果时全部关闭。
5. 键盘：Tab 顺序、焦点可见、← / → 翻页、对话框的焦点循环都不变。
6. 指标：CLS 为 0；本地 LCP 增量 ≤ 250ms；动效期间没有超过 50ms 的长任务；首屏 ≤ 300 KB。
7. 打印预览、手机浏览器顶栏颜色、分享卡片标签。
8. `bin/ci` 全绿。

**评分锚点**（自评时引用）

- 设计 7.5：清单 1–3 全过，且能说出每个页面的视觉重心在哪。8.5 以上要有外部意见佐证，不自封。
- 可用性 8：清单 4–5 全过，任何动效都不拖慢操作。
- 创意 7.5：M1–M6 全部到位，在同一个纸墨比喻下读得通；登录页和 404 有让人记得住的画面。
- 内容 7.5：E1、E2、T1 生效，第 2 节列出的内容问题清零。
- 开发者各 7.5：语义（唯一 h1、地标、标题层级）；动效（只动合成属性，没有长任务）；无障碍（不退步）；性能（清单 6）；响应式（清单 2）；元信息（D1、D2）。

最后一轮在生产环境复核：合并后由 CI 自动部署，再用产品负责人的 Chrome 按这次评估的页面和宽度走一遍。

## 8. 测试

- Vitest：墨块副本的裁切计算；书签盖章的两态；键盘翻页的各种忽略条件；开场只播一次；打印前渲染全部来源。
- Rails：摘要清洗去尾巴（含真实样本）；旧条目展示时去尾巴；片段边界；`<head>` 标签。
- 系统测试：切来源照常工作；← / → 翻页；减少动态效果时没有动画（用 CDP 模拟）；打印媒体下三个来源都可见。
- 已有测试全部保持通过。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 翻页过渡与 Inertia 的滚动恢复、焦点移动冲突 | 只给整页跳转开；系统测试覆盖后退、前进与焦点 |
| 开场动画推迟可读时间 | 总长 ≤ 600ms，每个会话只播一次，量 LCP 增量 |
| 墨块副本在索引条换行或字体还没加载时错位 | 用 ResizeObserver 与 `document.fonts.ready` 重算；矩阵逐个宽度检查 |
| 字体声明改成异步后，正文中文先用回退字体、再换成文楷 | 现在分片也是按需下载、一样会换字，差别只是多一次请求；量冷缓存下的 CLS |
| 各浏览器支持程度不同（Safari、Firefox 缺某些特性） | 全部渐进增强：不支持就退回现在的样子 |
| 搜索结果里同一链接连日重复（不在本文范围） | 建议另开：按链接合并结果，并标出其他出现日期 |
